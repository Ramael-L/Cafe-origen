 Café Origen - Analítica

Proyecto de JavaScript para analizar las ventas
de la empresa Café Origen.

 Objetivo

Aprender a trabajar con arreglos, objetos,
funciones y análisis de datos.

 Tecnologías

- JavaScript
- Node.js
- Git y GitHub

 Ejecución

Para explorar las ventas:

node src/explorar.js
